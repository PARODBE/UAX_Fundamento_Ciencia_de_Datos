# Data del proyecto

- `DILIst_FDA.csv`: conversión del archivo DILIst de la FDA que acompaña al proyecto. Se quitaron espacios sobrantes de los encabezados y se normalizaron dos nombres de columna; los registros y etiquetas se conservaron.
- Las tablas con estructuras, InChIKey y descriptores RDKit todavía se generan en la ejecución de Colab mediante PubChem. Para que sean compartidas desde GitHub, deben exportarse aquí una vez completada esa preparación.
