# Notebooks del proyecto

Puedes abrir cada fase directamente en Google Colab con los botones. Los notebooks incluyen las salidas de su última ejecución y los comentarios de cada línea de código.

1. **Fase 2:** lee DILIst y el mapa de estructuras, calcula los descriptores RDKit y crea los CSV de datos depurados, entrenamiento y prueba.
2. **Fase 3:** realiza el análisis exploratorio con entrenamiento.
3. **Fase 4:** ajusta y evalúa la regresión lineal para MolLogP.
4. **Fase 5:** ajusta y evalúa la regresión logística para DILI.
5. **Fase 6:** explora los conglomerados a partir de cinco descriptores.

Las fases 3 a 6 descargan los CSV publicados en la carpeta [`Data`](../Data/README.md), así que no hay que subir archivos manualmente a Colab.
